## Como funciona

O GitHub Pages publica a raiz do repositório. O arquivo `index.html` abre o site e o `script.js` carrega o `README.md`.

## Checklist

- Conferir se o `README.md` está atualizado.
- Conferir se os títulos principais usam `#`.
- Conferir se os subtítulos usam `##` ou `###`.
- Conferir se os blocos de código estão fechados.
- Conferir se links internos fazem sentido.
- Conferir se `Curso_Python/.obsidian/` não foi alterado.
