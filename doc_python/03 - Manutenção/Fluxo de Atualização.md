# Fluxo de Atualização

Fluxo recomendado para adicionar, revisar ou publicar conteúdo.

## Mapa

- [[00 - Mapas/Mapa do Curso|Mapa do Curso]]

## Passos

1. Planejar a seção no cofre.
2. Criar ou atualizar arquivos em `conteudos/`.
3. Revisar a ordem didática.
4. Consolidar o conteúdo público no `README.md`.
5. Testar o site.
6. Conferir o status do Git.
7. Publicar.

## Ao criar nova seção

- Criar `conteudos/secao_XX/`.
- Criar `README.md` da seção.
- Criar arquivos de aula.
- Criar uma nota em `01 - Seções`.
- Criar blocos se a seção trouxer novos temas.
- Atualizar [[00 - Mapas/Mapa do Curso|Mapa do Curso]].
