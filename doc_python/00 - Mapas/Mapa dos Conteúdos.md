# Mapa dos Conteúdos

Este mapa liga o cérebro Obsidian à pasta editável `conteudos/`.

## Fonte editável

```text
conteudos/
```

## Regra

Tudo que é aula, exercício, projeto ou exemplo Python deve ficar dentro de uma pasta de seção em `conteudos/`.
