# Fluxo GitHub Pages

Este mapa mostra como o conteúdo sai do repositório e chega ao site público.

## Fluxo principal

```text
conteudos/
  -> README.md da raiz
  -> index.html
  -> script.js
  -> GitHub Pages
```

## Papel do cofre

O cofre Obsidian ajuda a planejar e conectar ideias, mas não deve ser a única fonte do conteúdo publicado.

O conteúdo final para o aluno deve estar consolidado no `README.md` da raiz ou nos arquivos públicos que o site carregar no futuro.

## Antes de publicar

- Revisar a trilha no cofre.
- Conferir a seção em `conteudos/`.
- Consolidar a versão pública no `README.md`.
- Testar a navegação no navegador.
- Verificar `git status`.
- Confirmar que `Curso_Python/.obsidian/` não foi alterado.
