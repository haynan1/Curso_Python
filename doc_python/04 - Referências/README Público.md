# README Público

Referência interna sobre o `README.md` da raiz.

## Papel

O `README.md` é a versão pública e navegável do curso no GitHub Pages.

## Arquivo no repositório

```text
../README.md
```

## Deve conter

- Apresentação do curso.
- Trilha de aprendizagem.
- Estrutura pública.
- Regras de manutenção importantes.
- Conteúdo consolidado para o aluno.

## Não deve conter

- Rascunhos longos.
- Planejamento solto.
- Notas pessoais ainda confusas.
- Configurações do Obsidian.
