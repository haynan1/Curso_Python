# Regras do Cofre

Este cofre existe para organizar conhecimento, não para guardar configuração do Obsidian manualmente.

## Regra absoluta

Nunca edite, apague, mova ou renomeie arquivos dentro de:

```text
Curso_Python/.obsidian/
```

## Pode editar

- Notas `.md` fora da pasta `.obsidian`.
- Mapas de conteúdo.
- Resumos de aulas.
- Planejamento de novas seções.
- Links entre conceitos.
- Checklists de publicação.

## Não faça

- Não use `.obsidian` como pasta de notas.
- Não mova notas para dentro de `.obsidian`.
- Não dependa de plugin para o site público funcionar.
- Não trate rascunho como conteúdo final.

## Convenção de links

Use links internos do Obsidian:

- Link simples para uma nota pelo nome.
- Link com caminho de pasta quando houver risco de duplicidade.
- Link com texto visível quando o título técnico da nota não for a melhor leitura.

## Convenção de organização

- `00 - Mapas`: navegação e visão geral.
- `01 - Seções`: notas centrais de cada seção do curso.
- `02 - Blocos`: conceitos agrupados por tema.
- `03 - Manutenção`: publicação, atualização e estrutura.
- `04 - Referências`: ponte entre cofre e arquivos do repositório.
