"IMC é peso dividido
pela altura ao quadrado."

## Conteúdo estruturado

### Explicação

Neste exercício aprendemos:

1) Como usar fórmulas matemáticas
2) Como utilizar parênteses corretamente
3) Como montar frases com variáveis

O que é IMC?

IMC significa:
Índice de Massa Corporal.

Fórmula:

IMC = peso / (altura * altura)

Ou também:

IMC = peso / (altura ** 2)

Por que usamos parênteses?

Porque primeiro precisamos calcular:
altura * altura

Depois dividir o peso pelo resultado.

Se não usarmos parênteses,
a ordem pode ficar incorreta.

Sobre as reticências (...)

O símbolo "..." é chamado de ELLIPSIS.
Ele é um objeto especial do Python,
mas normalmente aparece como marcador
para indicar que algo ainda será implementado.

Depois foi substituído pela fórmula correta.

Entendendo o print:

print(nome, "tem", altura, "de altura...")

O print junta tudo automaticamente
colocando espaços entre os argumentos.

Fluxo mental:

Variáveis → Fórmula → Resultado → Exibição
