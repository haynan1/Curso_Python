# Seção 3 - Lógica de Programação em Python

Esta seção é a base prática do curso. Ela contém os arquivos Python editáveis usados para estudar fundamentos da linguagem, lógica de programação, repetição, coleções, tratamento de dados e projeto CPF.

## Estado

Em produção.

## Objetivo

Levar o aluno de scripts simples até um projeto de validação de CPF, passando pelos principais fundamentos necessários para continuar em funções, organização de código e projetos maiores.

## Arquivos

Esta pasta contém:

- 69 arquivos `.py`;
- 1 `README.md` da seção;
- exemplos executáveis;
- explicações em comentários e docstrings;
- exercícios e gabaritos;
- material de apoio gerado para estudo.

## Blocos da seção

| Bloco | Arquivos | Tema |
| --- | --- | --- |
| Preparação | `01` | Testes curtos e avaliação de expressões |
| Fundamentos | `02` a `16` | Comentários, saída, tipos, variáveis, operadores, entrada e formatação |

## Ordem de estudo

1. Execute os arquivos em ordem.
2. Leia os comentários e docstrings.
3. Altere exemplos pequenos.
4. Resolva exercícios sem olhar o gabarito.
5. Registre dúvidas no Obsidian.
6. Atualize a nota correspondente em `doc_python/`.
7. Consolide o que for público no `README.md` da raiz.

## Critérios para concluir

O aluno está pronto para sair desta seção quando conseguir:

- explicar entrada, processamento e saída;
- criar variáveis e converter tipos;
- usar condicionais sem errar indentação;
- criar repetições com `while` e `for`;
- manipular strings e listas;
- tratar erros simples;
- entender o cálculo do CPF;
- adaptar o projeto final.
