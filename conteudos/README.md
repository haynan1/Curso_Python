# Conteúdos do Curso Python

Esta pasta é a fonte editável do curso. Todo conteúdo de aula, exercício, projeto ou rascunho didático deve nascer aqui antes de ser consolidado no `README.md` público.

## Papel desta pasta

- Guardar arquivos Python alteráveis.
- Separar o curso por seções.
- Manter um `README.md` dentro de cada seção.
- Servir como fonte para o cérebro Obsidian em `../doc_python/`.
- Servir como base para a publicação no GitHub Pages.

## Fluxo de trabalho

1. Criar ou editar arquivos dentro da seção correta.
2. Atualizar o `README.md` da seção.
3. Atualizar as notas correspondentes em `../doc_python/`.
4. Consolidar a versão pública em `../README.md`.
5. Testar o site localmente.

## Regra importante

Os arquivos dentro de `conteudos/` são a fonte editável. O `README.md` da raiz é a versão pública consolidada.
