# Conteúdos do curso

Esta pasta guarda os materiais de apoio, rascunhos e arquivos Python usados para construir as sessões do curso.

## Organização

- `secao_3/`: seção atual com arquivos de aula em Python.
- Cada nova seção deve ganhar uma pasta própria, como `secao_04/`.
- Cada seção deve ter um `README.md` com objetivo, ordem das aulas e critérios para avançar.

## Fluxo recomendado

1. Criar ou atualizar os arquivos da seção em `conteudos/`.
2. Testar os exemplos Python localmente.
3. Consolidar a versão didática final no `README.md` da raiz.
4. Conferir o site pelo `index.html`.

Consulte `../docs/GUIA_DE_ATUALIZACAO.md` para o passo a passo completo.
